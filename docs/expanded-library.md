# Rings and pulling expansion

Added five ring movements: assisted squat, biceps curl, feet-assisted vertical pull-up, low push-up, and feet-assisted support hold. Together with existing rows and incline presses, there are seven ring exercises.

Added neutral-grip pull-up and a timed pull-up top hold. Slow-lowering work is a prescription on the existing pull-up, not a duplicate library entry. Chin-ups, negatives, scapular pulls, hangs, and band-assisted pull-ups retain their existing IDs. The new neutral-grip entry separates palms-facing pulling from overhand pulling; the hold has a timed target rather than repetitions.

The pulling selector changes the B-day pulling slot without adding sets. Harder choices revert to assisted work in easier mode. Feet-assisted ring pulls remain available with reduced reps in easier mode. Missing selected equipment falls back through existing equipment handling. Saved profile choices are normalized and retained; old profiles still default to band assistance.

References: https://gmb.io/rings/ and https://www.acefitness.org/continuing-education/certified/february-2025/8800/the-ace-do-it-better-series-chin-ups/. Original app cues and targets; no paid programming copied.

Seven generated human illustrations are stored in public/exercises under their exercise IDs. Created with built-in image generation and visually inspected for full-body framing, contact points, and movement position. These are still illustrations, not filmed demonstrations. Shared prompt: photorealistic full-body athletic adult man in blue shirt and charcoal shorts, dark gym with blue lighting, realistic anatomy, no text or logos. Each prompt then specifies the named movement, grounded versus suspended feet, grip, and arm position. Slow-lowering image was excluded when that duplicate library entry was consolidated.
